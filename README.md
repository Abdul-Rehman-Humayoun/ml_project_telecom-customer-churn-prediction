# Telecom Customer Churn Prediction Using Machine Learning

**Jupyter Notebook semester project | BSAI 5A | Group 08**

**Team members:** Abdul Rehman (70176650) and Syed Hussain Abbass (70176788).

## Overview

This project uses the IBM Telco Customer Churn dataset to investigate customer churn, clean and preprocess data, train classification models, compare performance using cross-validation, tune hyperparameters, evaluate a selected model on a held-out test set, and demonstrate predictions on customer records. The deliverable is a **Jupyter Notebook**, not a deployed web application.

## Dataset

- **Name:** IBM Telco Customer Churn
- **Source:** https://www.kaggle.com/datasets/blastchar/telco-customer-churn
- **CSV:** `datasets/10_telecom_customer_churn_prediction/WA_Fn-UseC_-Telco-Customer-Churn.csv`
- **Target:** `Churn` (`Yes`/`No`)
- **Known cleaning concern:** `TotalCharges` contains non-numeric blank values.

Dataset is credited to its original publisher. Check the source's usage terms before redistribution.

## How to run

1. Download or clone this repository.
2. Open a terminal in the repository root.
3. Create and activate a virtual environment (optional but recommended).
4. Install dependencies: `python -m pip install -r requirements.txt`
5. Launch Jupyter: `jupyter notebook`
6. Open `notebooks/Group_08_5A_Telecom_Customer_Churn_Prediction.ipynb` and select **Kernel → Restart & Run All**.

**Important:** The notebook finds the CSV using a relative path, so launch Jupyter from the repository root or from the `notebooks` directory. It creates a `models/` folder relative to the current working directory when saving the trained pipeline.

## Methodology

- Dataset understanding and data quality assessment
- Cleaning, EDA, and feature preprocessing
- Baseline Dummy Classifier, Logistic Regression, Decision Tree, and Random Forest
- Stratified cross-validation, GridSearchCV, and RandomizedSearchCV
- Held-out test evaluation with accuracy, precision, recall, F1-score, ROC-AUC, and confusion matrix
- Final model persistence with joblib and sample churn predictions
